## 🤖 Reinforcement Learning & Simulation

### 🔹 [PROJECT ARES — Mars Colony RL Governor](https://github.com/Mohankirushna/Ai_mars_colony_reinforcement)
A PPO-based deep RL agent that governs a 100+ colonist Mars settlement across 1000+ Martian sols, balancing resources against disasters (dust storms, meteors, disease). Features a 38-action space, multi-objective reward engineering, statistical significance testing, and a live Next.js dashboard.

### 🔹 [PRCS — Predictive Ride Comfort System](https://github.com/Mohankirushna/Pothole_dynamic_suspention)
An AI-powered predictive suspension controller combining computer vision, vehicle dynamics simulation, and reinforcement learning. Detects road damage via an 86.4% F1-score YOLO ensemble and adjusts suspension 50–200ms *before* impact.
